# Arena Hero V2

Versão 2 do jogo Android, focada em:
- gráficos 2D com iluminação, sombras, partículas e efeitos de impacto;
- combate com ataque normal e habilidade desbloqueada no nível 2;
- inimigos com nível crescente;
- XP, níveis, ataque, defesa e vitórias;
- controles por toque para jogar no celular.

Application ID: com.example.gamev2
Version: 2.0
